Prepare: datasets, sessions, subsets

The top of the Prepare tab handles everything before the pipeline: building datasets from uploads, previewing on a subset, and managing what you have.

How the pieces fit

  • Dataset: the spectra you chose, copied into durable storage, with one technique (vibrational or XPS).
  • Session: created automatically whenever you pick, create or import a dataset. It holds your working pipeline and current subset. The line “Session: …” is informational; there is no button to create one.
  • Subset: a few randomly chosen spectra used only for preview plots. Batch feature extraction and Analyze always use the full dataset.

Picking a different dataset empties the pipeline editor and clears the subset.

Create new dataset

  1. Select spectra in the tree. Ticking a whole file takes all of its spectra: one file is enough for a series or a map. For multi-region XPS files, tick individual block rows to take only those.
  2. Narrow the list if needed:
    • Select all visible and Clear.
    • Range (vibrational): groups files by spectral range in 100 cm⁻¹ steps; choosing a group replaces your selection.
    • XPS region: selects matching region blocks across files (shown instead of Range when XPS files outnumber vibrational ones).
    • Filters: pick label values (AND between keys, OR within a key). Filters only hide rows in the picker; they do not alter what a ticked file contains.
  3. For XPS, optionally use Regions to keep only some regions. “all valence bands” matches any region with valence, fermi or vb in the name.
  4. Optionally type a Dataset name (duplicates are allowed; blank gives “Unnamed dataset …”).
  5. Press Create dataset.
  • No mixing. A dataset cannot hold both XPS and vibrational files. Deselect one technique first.
  • Averages only by default. Ticking a whole VAMAS/NeXus file keeps only its averaged spectra. To include individual replicates, tick the individual block rows.
  • Files that cannot be read are skipped, with a banner naming the first few. Only if nothing loads does creation fail.

Afterwards the dataset is active, a session exists and the pipeline editor is empty. The subset is empty too, so press Create subset before expecting a plot.

Datasets keep their own copy of the data. Hiding or purging uploads later does not break them.

The Plot card

  • View: Raw (subset) = untouched source spectra; Final = after the whole pipeline (if it ends in a fit you get fit + residual figures per spectrum); After: <step> = the result right after that step (steps appear by internal name, for example After: baseline). Use “After:” to debug one step at a time.
  • Subset size: 1–30, default 15. At most 30 spectra are ever plotted.
  • Subsets: tiles of saved subsets (up to 15 per dataset, stored in this browser only). Click a tile to reuse exactly those spectra, Delete to drop it, Clear all subsets to reset.
  • After reloading the page your settings return, but the active subset does not: click a tile or Create subset.
Use a fixed set of tricky spectra (noisy, spiky, high background) as a saved subset and re-check it after every change to your pipeline.
