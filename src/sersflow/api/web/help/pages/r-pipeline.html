Prepare: the pipeline builder

A pipeline is an ordered list of steps applied to every spectrum. You build it in the Pipeline card at the bottom of the Prepare tab and preview the effect in the Plot card above it.

Pipeline type

The selector offers Vibrational (Raman / SERS / FTIR) and XPS. With a dataset loaded, its technique wins; the other choice is refused (“Pipeline type must match the loaded dataset”). The type changes:

  • the fitting engine: SciPy curve_fit (vibrational) or lmfit with constraints and XPS backgrounds (XPS);
  • the available steps (Cosmic Ray Removal is vibrational only) and baseline families (Shirley/Tougaard only for XPS);
  • the “Saved” library list, filtered to the current technique.

Adding and arranging steps

The palette has four groups; press + <step> to append a step with default settings and select it:

GroupSteps
Data PreparationCropping, Low-Signal Filter, Metadata Filter, Outlier Detection
PreprocessingAlignment & Resampling, Baseline Correction, Cosmic Ray Removal, Smoothing, X-axis Calibration
TransformationNormalization, Reference Transformation, Derivative
Feature ExtractionMetric Calculation, Peak Fitting, Peak Integration, Peak Identification

Each step is described in Pipeline steps A–Z. A step can be added more than once.

Each row of the step list has:

  • N. name: click to select it and edit its parameters on the right. N is the position in the list and includes disabled steps.
  • ↑ / ↓: move. Moving renumbers.
  • OFF / ON: the button shows the action; it reads OFF while the step is enabled. A disabled step passes data through. Disabling a step that others refer to (a fit used by a calibration, a baseline used by a normalization) breaks those references.
  • Del: deletes the step without asking.
  • Input XY for this step: Previous (default), Initial (the raw spectrum, restarting the chain) or After step K. Use it to branch, for example to fit from the raw data while another branch is processed.
Low-Signal Filter and Outlier Detection do not change spectra; they remove whole spectra, judged on the output of the steps above them. Place them accordingly.

Previewing

Use the Plot card's View: Raw (subset), Final, or After: <step> (steps are listed by internal name, such as After: baseline or After: x_axis_calibration; see the table in Pipeline steps A–Z) to see the result of any single step. With Auto-run on, edits redraw automatically; for “After:” views press Run preview plot (subset) after editing parameters. See Prepare: datasets, sessions, subsets.

Saving, loading, sharing

ButtonWhat it does
Save pipelineWrites the editor to the active session. Previews do this automatically, but press it before going to Analyze.
Export current pipelineDownloads <name>.sersflow-pipeline.json built from the editor. No session needed.
Name (optional) + Save to libraryStores a named copy in the shared pipeline library, so it can be reused on other datasets and used by Analyze. Blank gives “Unnamed pipeline …”. A name already in use is refused unless Overwrite if name exists is ticked.
Saved dropdownChoosing an entry loads it immediately, discarding unsaved edits without asking, and writes it to the session.
Reload, Update selected, Delete selected, Export selected, Refresh listRe-fetch the saved entry; rename or replace its steps; delete it; download it; refresh the list.
Import pipelineAdds a downloaded pipeline file to the library and selects it, but does not load its steps. Press Reload to load them.
Save a new name for every meaningful variant instead of overwriting. The exported feature tables and manifests identify a run by its pipeline, so a stable named pipeline is your record of what was done.

Rules that stop you

  • No double XPS background. A static Shirley/Tougaard baseline step cannot be enabled together with an active shirley_bg/tougaard_bg component in a fitting step. A red banner appears and saving is refused. Choose one. See XPS specifics.
  • The pipeline's technique must equal the dataset's technique.

Good starting chains

  • SERS / Raman: Cropping → Cosmic Ray Removal → Smoothing → Baseline Correction → Normalization → Peak Fitting or Peak Integration.
  • XPS: Metadata Filter (one region) → X-axis Calibration → Peak Fitting with a recipe (active Shirley background) or a static Shirley baseline plus peaks → Metric Calculation.
