Raw visualization tab

Look at your data exactly as measured, before any processing. Nothing here changes or stores anything.

Plotting

  1. Pick a file in Files to plot. Press + to add another selector (− removes one).
  2. The plot appears automatically. Changing a file, a tick, Plot mode or Stack separation redraws after a moment. Plot spectrum forces a redraw.
  3. Choose Plot mode: Overlay (all traces on top of each other) or Stack (each trace shifted up by Stack separation, default 1000, in intensity units, in trace order).

Drag the divider between the list and the plot to resize it. Only files you have not hidden are listed.

What you get depends on the file

File typeExtra controls
Single spectrumNone. x = first column, y = second.
Time series (3-column text, WDF series)Time/Depth points slider with All / None. Move the bar, and click it to toggle points. Starts with point 0 only.
Map (WDF map, 4-column text)Map points: click cells to toggle them; a preview image of the mapped area sits behind the grid. All points start selected.
Multi-region XPS (VAMAS / NeXus)Multi-spectrum blocks: Add filter / Clear filters. By default only the averaged spectra of the first region are shown. Tick individual blocks to override the filters. Categorical fields use tick boxes (matching any ticked value); numeric fields use an operator (=, !=, >, …) and a number. Several filter rows combine with AND.
30-trace limit. At most 30 spectra are drawn. If you select more (for example all points of a map), only the first 30 are plotted, without a warning. Select fewer points, or use the heatmap view for series.

Series heatmap

Select exactly one time-series file and press Series heatmap. It shows time on one axis, wavenumber on the other and intensity as colour: a quick way to see changes over time. A file that is not a series answers “Not a series dataset”.

What to look for

  • Is the x axis in the right range and unit (wavenumber in cm⁻¹ or binding energy in eV)?
  • Are there spikes (cosmic rays), a steep background, saturated or empty spectra?
  • Do spectra within a group look alike? This tells you which cleaning steps you will need in Prepare.
