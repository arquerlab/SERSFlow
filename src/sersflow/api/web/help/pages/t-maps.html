Tutorial 4 · Maps and time series

Goal: handle files that contain many spectra in space (maps) or in time (series), see them as heatmaps and extract a feature for every point.

⏱ about 25 minutesLevel: beginner (after Tutorial 1)Data: your WDF/text files, or the sample set below

Before you start

⬇ Download sample series + map (zip) It contains two synthetic text files: a time series of 20 spectra (the 1580 cm⁻¹ band grows, the 1080 cm⁻¹ band decays) and a 4 × 4 map with a hot spot near position (15, 10) µm.

KindFileWhat each spectrum has
Time series3-column .txt (time, x, intensity) or a WDF seriesaxis_time_s
Map4-column .txt (position x, position y, x, intensity) or a WDF mapaxis_map_x, axis_map_y

One file is enough: when you create a dataset from it, it expands into one spectrum per time point or map position.

For 3- and 4-column text files SpecFlow still reads the technique from the first header cell, so it must contain a word such as Raman or wavenumber (the sample uses “Raman time (s)” and “Raman X (um)”). WDF files do not need this.

1. Look at the raw data

  1. Uploads → upload both files.
  2. Raw visualization → select the timeseries file. Use the Time/Depth points slider; click the bar to add points. For the map file, click cells in Map points (at most 30 traces are drawn).
  3. With exactly the time-series file selected, press Series heatmap.
Two horizontal bands (near 1080 and 1580 cm⁻¹); the lower one fades and the upper one brightens as time increases.

2. Build a dataset and pipeline

Follow steps 3–4 of Tutorial 1 for each file (a dataset timeseries_run43 from the series file, and map_run43 from the map file). A short pipeline is enough: + Cropping (850–1750), + Baseline Correction (asls, 1e6, 0.01), + Peak Integration with band1 1050–1110 and band2 1550–1620. Save it, for example as maps_v1.

  • Check several subset spectra from different places and times (Resample): the same settings must work for all.
  • For real maps, add + Cosmic Ray Removal and a + Low-Signal Filter to drop dead points.

3. Run and make heatmaps

  1. Analyze → dataset map_run43 and pipeline maps_v1 → Run feature extraction (async) → wait for completed and select the run.
  2. Section → Heatmaps. Choose Feature area_band2.
  3. Files: All files; Layout: Individual plots; press Plot heatmaps.
  4. Click any cell to overlay the processed spectrum of that position underneath; Clear spectra resets.
A 4 × 4 colour map with one bright region around x = 15, y = 10 µm. For the series dataset, the same section gives a single row along time.
If you see “No map/time rows with numeric values were found for this feature”, the feature is empty for those spectra (for example a window outside the cropped range), or the files have no map/time axes.

4. Time courses and correlations

  • Plots → Parameter vs parameter: X = axis_time_s, Y = area_band1 and area_band2, style Line (sorted by X, no error). Run the analysis on timeseries_run43 first.
  • For several files with the same conditions, use Mean ± error bars (group by X).
  • Correlation / VIF and PCA / Cluster work as in Tutorial 1; colour PCA scores by axis_time_s to see trajectories.

5. Whole-spectrum analysis (optional)

To analyse the full spectra instead of picked bands, use Spectrum matrix & PCA: add + Alignment & Resampling after Cropping so all spectra share one grid, start a matrix job and run Run discrete PCA or k-means (PC embedding). The loadings are spectra: they show which wavenumbers drive each component. See Spectrum matrix & PCA.

Export

The observation table has axis_time_s, axis_map_x, axis_map_y, grid_nx, grid_ny and file_kind, so you can re-plot maps in any external tool.
