Tutorial 3 · Maps and time series

Goal: handle files that contain many spectra in space (maps) or in time (series), see them as heatmaps and extract a feature for every point. About 20 minutes.

What counts as a map or a series

KindFileWhat each spectrum has
Time series3-column .txt (time, x, intensity) or a WDF seriesaxis_time_s
Map4-column .txt (position x, position y, x, intensity) or a WDF mapaxis_map_x, axis_map_y

One file is enough: when you create a dataset from it, it expands into one spectrum per time point or map position.

1. Look at the raw data

  1. Uploads → upload the file.
  2. Raw visualization → select it. For a series, use the Time/Depth points slider; for a map, click cells in Map points. At most 30 traces are drawn.
  3. For a series, press Series heatmap (exactly one file selected): time against wavenumber, colour = intensity. You will see when bands appear, shift or disappear.

2. Build a dataset and pipeline

Follow steps 3–4 of Tutorial 1. For maps and series, especially:

  • Use Cosmic Ray Removal and a Baseline: the same settings must work for hundreds of spectra, so check several subset spectra from different places and times (Resample).
  • Add a Low-Signal Filter after Cropping to drop dead or empty acquisitions (choose the threshold from the histogram).
  • End with Peak Integration or Peak Fitting for the band(s) you want to map.

3. Run and make heatmaps

  1. Analyze → dataset + pipeline → Run feature extraction (async) → wait for completed.
  2. Section → Heatmaps. Choose a Feature (for example area_band1).
  3. Files: All files, Single file or Multiple selected; Layout: Individual plots or Subplots; press Plot heatmaps.
  4. A map gives a 2-D colour map; a series gives a single row along time. Click any cell to overlay the processed spectrum from that position underneath; Clear spectra resets.
If you see “No map/time rows with numeric values were found for this feature”, the feature is empty for those spectra (for example a window outside the cropped range), or the files have no map/time axes.

4. Time courses and correlations

  • Plots → Parameter vs parameter: X = axis_time_s, Y = a feature, style Line (sorted by X, no error).
  • For several files with the same conditions, use Mean ± error bars (group by X).
  • Correlation / VIF and PCA / Cluster work as in Tutorial 1; colour PCA scores by axis_time_s to see trajectories.

5. Whole-spectrum analysis (optional)

To analyse the full spectra instead of picked bands, use Spectrum matrix & PCA: add Alignment & Resampling after Cropping so all spectra share one grid, start a matrix job and run Run discrete PCA or k-means (PC embedding). The loadings are spectra: they show which wavenumbers drive each component. See Analyze tab.

Export

The observation table has axis_time_s, axis_map_x, axis_map_y, grid_nx, grid_ny and file_kind, so you can re-plot maps in any external tool.
