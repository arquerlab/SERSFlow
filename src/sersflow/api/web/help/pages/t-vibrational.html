Tutorial 1 · SERS / Raman: files to correlation

Goal: turn a folder of Raman/SERS files into a table of band areas, check how two bands relate, and export the result. FTIR data follow the same path.

⏱ about 30 minutesLevel: beginnerData: your own spectra, or the sample set below

Before you start

Use your own files, or download the practice data. It is synthetic: ten spectra of a silver-nanoparticle sample at potentials from −0.1 to −1.0 V, with two bands (about 1080 and 1580 cm⁻¹) that trade intensity as the potential changes, a fluorescence background, noise and a few cosmic-ray spikes.

⬇ Download sample SERS files (zip) Unzip it to a local folder (not OneDrive “online-only”).

The potential is in the file names, for example AgNP_785nm_1p_2s_pH7_-0d3VRHE_0d1M_KHCO3_CO2.txt. SpecFlow reads sample, laser, pH, potential, electrolyte and gas from such names (Labels and file naming).

1. Upload and check labels

  1. Open the Uploads tab. Choose your folder with the folder picker (extension filter Only, txt,wdf) and press Upload.
  2. In Uploaded files & metadata, read the summary beside each file. Tick one file: the Edit labels panel on the right shows what was read.
Each file shows AgNP · pH=7 · CO2 · −0.3VRHE · 785nm · 1% · 0.1M KHCO3 (with its own potential). In Edit labels: sample AgNP, gas CO2, ph 7, potential_V −0.3, potential_ref VRHE, laser_nm 785, laser_power_pct 1, electrolyte KHCO3, concentration_M 0.1.
Fix labels now. They become the meta_* columns of your results and the colours and filters you use later.

2. Look at the raw spectra

  1. Open Raw visualization and select a file; use + to add more files and compare them in Overlay or Stack mode.
  2. Note: spikes? a slanted background? weak or empty spectra? Here you will see two bands on a large curved background and a few one-point spikes.

3. Create a dataset

  1. Open Prepare. In Create new dataset tick the ten files (or Select all visible).
  2. Type a Dataset name, for example run42, and press Create dataset.
  3. Press Create subset to draw a few random spectra for previews (set Subset size to 3–5 for a clearer view).
The dataset bar shows run42 (ds_…) — 10 and a session id; the Plot card (View = Raw (subset)) shows your spectra.

4. Build the pipeline

Add steps from the palette in this order, previewing after each. Set View to After: <step> (for example After: baseline) to see exactly what one step did; press Run preview plot (subset) after editing a parameter in an “After:” view.

  1. + Cropping: set min_x 450 and max_x 1800.
  2. + Cosmic Ray Removal: keep zscore, threshold 5, window 5 (odd). Check on a spiky spectrum that spikes vanish and the real bands stay.
  3. + Smoothing: window 11, polyorder 3.
  4. + Baseline Correction: asls, lam 1e6, p 0.01.
  5. + Peak Integration: window band1 = 1050–1110, then + Add window for band2 = 1550–1620.
  6. + Peak Fitting (optional, for fitted positions and widths): two Lorentzian components, centres 1080 and 1580 (bounds ±30), amplitude Auto, FWHM 25 with bounds 5–60. See Peak fitting.
With After: baseline the spectrum sits near the baseline-corrected curve, and the baseline estimate runs under the bands without touching their tops. With After: fitting you see data, fit, components and a residual panel for each spectrum.
Peak Integration does not remove a baseline by itself. That is why Baseline Correction comes before it. And because Peak Fitting replaces the spectrum with the fitted curve, anything that must see the data (like Peak Integration) goes before the fit.
  1. Switch View to Final and check several subset spectra (press Resample for new ones). Save tricky ones as tiles and re-check them whenever you change something.
  2. Type a name such as run42_v1 and press Save to library, then Save pipeline.

5. Run it on all spectra

  1. Open Analyze. Choose your Dataset and the Pipeline you saved.
  2. Press Run feature extraction (async). Watch the progress line; the run appears in the Runs table.
Status goes pending → running → completed within seconds for ten spectra. The run is named “run42 run42_v1 00”.
If the run fails, read the message in Overview. Typical causes: crop that does not cover the data, a fit window left with no points, or a pipeline that was not saved. Fix, then start a new run.

6. Explore

  1. Select the finished run in Run, then Section → Correlation / VIF. Select area_band1 and area_band2 (and meta_potential_V) and press Run correlation.
  2. Section → Plots → Parameter vs parameter: X = meta_potential_V, Y = area_band1 and area_band2, style Line, press Plot.
  3. Optionally PCA / Cluster with StandardScaler and Run PCA. Remember the default plots start at PC2 vs PC3 (set X/Y PC to 1 to include PC1).
area_band1 falls and area_band2 rises as the potential becomes more negative, so they are strongly negatively correlated (r close to −1). That is the trend built into the sample data.

7. Export

In Exports press Observation wide CSV (labels + axes): one row per spectrum with your features, meta_* labels and axes. Also download the manifest if you need to document how it was made. Column meanings: Exports and column names.

What you learned

  • Preview on a subset, run on everything.
  • Order matters: crop → spikes → smooth → baseline → normalize → features.
  • Name and save your pipeline: it is the record of your processing.
