Uploads tab

The Uploads tab is the front door: it stores your instrument files on the server and shows the labels SpecFlow read from them.

Supported file formats

FormatExtensionTechniqueContains
ASCII XY table.txtfrom the headerSingle spectra, time series, maps.
Renishaw WDF.wdfVibrational (Raman/SERS)Single spectra, series, maps.
VAMAS / CasaXPS.vmsXPSMany regions (“blocks”) per file.
NeXus XPS (HDF5).nxs, .nx5XPSMany regions; regions without a binding-energy axis are skipped (the number skipped is shown in the list).

Text file rules

  • The first non-empty line is always a header. Tabs, commas, semicolons or spaces are detected automatically.
  • The number of columns decides the type: 2 = spectrum (x, intensity); 3 = time series (time, x, intensity); 4 = map (position x, position y, x, intensity). Any other count is an error.
  • The first header cell decides the technique: names such as wavenumber, raman shift, cm-1 mean vibrational; binding energy or BE means XPS. Anything else produces “Cannot infer technique” when you create the dataset, not at upload.
  • In time series, rows with negative time are dropped.

Uploading

  1. Use the file picker (several files) or the folder picker (keeps sub-folders, which is useful because folder names can supply labels). Or drag files onto the drop zone: dropping uploads immediately.
  2. Check Filter mode and Extensions. Only (default) keeps just the listed extensions; Skip drops them. Use the folder picker with Only to ignore stray files such as .csv or .png.
  3. Press Upload. Files go in batches of 25; progress shows as “Uploaded N/M files…”.
  • Single-spectrum files are stored without parsing. VAMAS and NeXus files are read at upload to find their blocks and labels.
  • Uploading the same file twice creates two independent copies.
  • The file's last-modified time is stored as the label acquired_utc.
If the status mentions “online-only” files, your folder is in OneDrive and not downloaded to the computer. Copy it to a local folder (for example C:\temp\) and upload from there.

Uploaded files & metadata

A tree of your folders and files: tick a folder to tick everything inside it. Each file shows its name, size, a summary of its labels (sample, pH, gas, potential, current, laser…) and, for multi-region files, the number of spectra. Multi-region files expand into indented block rows.

Your uploads are private to your user account. The Prepare tab updates automatically after changes made here.

Editing labels

The right-hand Edit labels panel shows a Key/Value table for the selected file(s). Labels matter: they become the meta_* columns in your exports, the filters in Prepare, and the colours in plots. See Labels and file naming for what is read automatically and how to edit by hand.
