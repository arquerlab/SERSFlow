Troubleshooting

Look for your symptom. The first column is what you see.

Uploading and datasets

SymptomCause and fix
Upload stalls or mentions “online-only”The folder lives in OneDrive and is not on disk. Copy it to a local folder.
“Unknown TXT layout”Text files need 2 (spectrum), 3 (series) or 4 (map) columns, and the first line must be a header.
“Cannot infer technique”The first header cell must say wavenumber / Raman shift / cm-1 (vibrational) or binding energy / BE (XPS).
“Selection mixes XPS and vibrational files”A dataset has one technique. Deselect one kind.
Labels missing or wrongRename files following Labels and file naming, or edit by hand. Reload auto labels overwrites manual edits.
XPS dataset has fewer spectra than expectedWhole-file selection keeps averaged spectra only. Tick block rows for replicates. NeXus regions without a binding-energy axis are skipped.
A file I hid is gone from PrepareHidden files vanish from pickers. Use Restore files to uploads from a dataset made from them.
Clear all datasets does nothingThe server has no bulk delete. Delete datasets one by one with Delete current dataset.

Preview in Prepare

SymptomCause and fix
“No active subset…”, empty plotPress Create subset (or click a saved tile). The subset is not restored after a reload.
Plot does not update after editing a parameter“After:” views do not auto-run on edits. Press Run preview plot (subset).
“Pipeline type must match the loaded dataset”Switch dataset to change technique, or build the right pipeline type.
Red banner about Shirley/TougaardA static baseline and an active background are both enabled. Keep one (XPS specifics).
Cropping gives an error or nothingNew Cropping steps start empty; fill min and max.
Spikes remain after Cosmic Ray RemovalLower the threshold, use an odd window, and run the step before the baseline.
Baseline eats the peaksRaise lam (or lower p); check with View → After: baseline.
Smoothing seems to do nothingWindow longer than the spectrum, or polyorder not below the window: the step silently returns the data unchanged.
Fit looks like the data, or later steps look strangeA fitting step replaces the spectrum with the model. Put normalization and integrations before it, or use Input XY = After step K to branch.
Fit does not converge / insufficient pointsSet peak centres near the real peaks, set FWHM bounds, widen the fit window, simplify the model.
Calibration does not shift the axisThe reference fit failed or no spectrum matched the reference filter: the shift is 0 with only a warning. Check the reference fit.
Outlier Detection error about a shared gridAdd Alignment & Resampling above it.
Filters “flag” but still remove spectraThe action setting has no effect: Low-Signal and Outlier filters always exclude.

Analyze

SymptomCause and fix
Sections show only a hintThe selected run is not completed. Wait, or pick another run.
Run stays pendingRuns execute one at a time on the server; another run is in progress.
Run failedCrop does not overlap the data, fit window empty, pipeline unsaved, or technique mismatch. Fix and start a new run.
Only one feature I_analysis_fallbackThe pipeline has no feature step. Add integration, identification or fitting.
Metric Calculation column is emptyA variable name does not match the real column (region or s<N>_ prefix), or an input is missing. Check the exported column names.
PCA uses fewer spectra than expectedOnly spectra with values in every selected column are used. Remove sparse columns from the selection.
PCA starts at PC2Default axes are PC2/PC3. Set X/Y PC to 1.
Scree plot emptySparse PCA gives no explained variance. Use plain PCA for scree.
My PCA download changedRe-running PCA overwrites the saved result of that run.
Matrix job: “inconsistent Raman shift grid”Add Alignment & Resampling after Cropping and set up_to_step to it or later.
FDA FPCA error (501)Install the optional package: pip install -e ".[explore-fda]".
Parquet export error (501)Install pyarrow on the server (pip install -e ".[parquet]").
“No map/time rows with numeric values…”The feature is empty for these spectra or the files have no map/time axes.

Still stuck?

  • Open the browser's developer console (F12) to see errors, and check the “Errors” box at the bottom of the page.
  • The interactive API reference is at /docs (link at the top of the page).
  • When asking for help, include the dataset name, pipeline name, run status, the exact message and what you pressed.
