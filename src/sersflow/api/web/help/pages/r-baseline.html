Baseline methods

Baseline Correction subtracts an estimated background: output = spectrum − baseline. The catalog comes from the server and is grouped into families.

Choosing

SituationStart with
SERS/Raman with broad fluorescenceasls (lam 1e5–1e7, p 0.001–0.05), or arpls / airpls
Complex, curved backgroundWhittaker or P-spline variants (pspline_*)
Quick, parameter-lightsnip (max_half_window), or morphological mor / mormol (half_window)
Smooth polynomial trendmodpoly, imodpoly (poly_order 2)
XPS core levelshirley or tougaard (family “lmfitxps (XPS)”)
Compare methods visually: View → After: baseline draws the input spectrum with the estimated baseline curve on top. Adjust until the curve touches the bottom of the peaks without cutting into them.

Two parameters that matter most

  • lam (smoothness): larger = stiffer baseline. Raise it if the baseline follows peaks; lower it if it misses broad fluorescence.
  • p (asymmetry): smaller = baseline hugs the bottom and ignores peaks more strongly.
  • half_window / max_half_window (morphological, SNIP): set about the widest peak width, in data points.

XPS: static backgrounds

Shirley and Tougaard here subtract a static background before fitting. The alternative is an active background inside the fit (see XPS specifics). Use one or the other, never both.
