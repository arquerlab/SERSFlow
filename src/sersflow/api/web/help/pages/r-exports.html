Exports and column names

Everything you download from Analyze is UTF-8, comma-separated, with a header row. Missing values are empty cells. Use the observation table whenever you want features and labels together.

Observation wide CSV

One row per spectrum. Column order:

  1. spectrum_id
  2. Feature columns in pipeline order (see below).
  3. Axes: axis_time_s, axis_map_x, axis_map_y, grid_nx, grid_ny, file_kind (single, series or map).
  4. Labels: meta_*, one column per label found in any file, alphabetical. Empty where a file lacks that label.
The observation table has no file-name column. If you need to know which file a row came from, put it in a label (for example sample) or use the PCA scores CSV, which includes the file path.

meta_ columns

These are the labels you saw in the Uploads tab (sample, gas, pH, potential, laser…). Names are made safe by replacing every run of characters other than letters, digits and underscore with _, then prefixed with meta_. Labels holding lists or dictionaries are written as JSON text.

When a pipeline has several steps of the same kind, names are prefixed s<N>_ (the step number). If two names would still collide, a suffix __2, __3… is added.

Give fit components short, meaningful IDs (for example CO_top or Co3O4) in the fitting editor: they end up in every column name.

Observation long CSV

Columns: run_id, dataset_id, spectrum_id, feature_key, value, kind, where kind is feature, axis or meta. The features-only long file has run_id, spectrum_id, feature_key, value, kind.

Manifest

A JSON record of the run: run_id, dataset_id, pipeline_hash, subset_hash, created_at, finished_at, feature_columns and the file format (encoding, delimiter, how missing values are written). Keep it with your results for reproducibility.

Uncertainties

Every fitted value has a 1σ error column: fit_[region_]<component>_<param>_stderr, …_area_stderr and …_area_pct_stderr. They come from the fit covariance, scaled by the reduced χ², and are propagated to area and %area through the peak links (ratios, shared widths). Fixed parameters have an empty error. Runs made before these columns existed show them empty until re-run. fit_[region_]gof_median_rel_stderr summarises them in one number.

For uncertainties that include the background and overlapping peaks, run a Monte Carlo job (Analyze → Plots → Fit diagnostics, or POST /analysis/runs/{id}/monte-carlo-jobs). Its zip has mc_summary.csv (best fit, covariance error, Monte Carlo mean, SD and 2.5/50/97.5 percentiles per spectrum, component and quantity), mc_replicates.csv (every refitted replicate) and mc_summary.json.

Publication fit report

Analyze → Plots → Fit diagnostics → Download report (API POST /analysis/runs/{id}/report-jobs; MCP post_analysis_report_jobs) builds a zip with:

  • report.html: one self-contained page (figures embedded) to read, print or save as PDF;
  • report.md: the same in Markdown, with the figures in figures/;
  • report.json: the machine-readable report (also GET /analysis/report-jobs/{job_id}/json; MCP get_analysis_report_json).

Contents, per the ISO 19830 / Major et al. reporting items:

  • Provenance: file name, block and SHA-256; software version and git commit; pipeline hash.
  • Acquisition (VAMAS files): source, excitation energy, source–analyser angle, pass energy, step, dwell, scans, counts and count rate at the most intense channel.
  • Charge correction: method, reference and the shift applied to each spectrum.
  • Processing history: every pipeline step with its parameters.
  • Fits, per region: background and fit window, and for each component the line shape in CasaXPS notation (GL(30), LA(α,β), …), position, FWHM, height, area and %area ± 1σ, and the status of every parameter (fixed, bounded [min, max], or linked with its relation).
  • Fit statistics: optimiser, N points, free parameters, χ², reduced χ², normalised residual STD, weighting.
  • Figure: data, envelope, components, background, residual and a component table.
  • Checklist of the reporting items.

Quantification (atomic %) is not available yet; the report says so.
