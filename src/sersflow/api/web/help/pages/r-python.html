Python client

Everything the web interface does is available over HTTP, and SersflowClient wraps it for Python scripts and notebooks. Use it to process many datasets in a loop, make figures for a paper, or embed SpecFlow in a larger workflow.

Install and connect

pip install -e ".[client]"          # adds httpx
sersflow-api                          # start the server (or use the one you already run)
from sersflow.client import SersflowClient

with SersflowClient("http://127.0.0.1:8000") as client:
    print(client.meta.health())
    # client.login("user", "password")   # only if the server requires authentication

The client has one attribute per area, mirroring the API: meta, io, datasets, sessions, pipelines (library), analysis, explore, fitting, plot, xps, metrics, raw.

Worked example: files to correlation-ready table

This is the script behind Tutorial 1, with a shorter pipeline. It uploads a folder, creates a dataset, runs the pipeline on every spectrum, exports the observation table and runs PCA.

from pathlib import Path

from sersflow.api.schemas.analysis import AnalysisRunCreateRequest
from sersflow.api.schemas.datasets import DatasetCreateRequest, DatasetMetadata
from sersflow.api.schemas.explore import PCARequest
from sersflow.api.schemas.pipeline import Pipeline, PipelineStep
from sersflow.api.schemas.sessions import SessionCreateRequest, SubsetStrategy
from sersflow.client import SersflowClient

DATA = Path("C:/data/run42")   # folder with your .txt spectra

with SersflowClient("http://127.0.0.1:8000") as client:
    # 1. upload a folder and create a dataset from it
    client.io.upload_folder(DATA)
    paths = [u.relative_path for u in client.io.list_uploads().items if u.filename.endswith(".txt")]
    ds = client.datasets.create(
        DatasetCreateRequest(relative_paths=paths, metadata=DatasetMetadata(name="run42"))
    ).dataset

    # 2. describe the pipeline (the same JSON the web UI saves)
    pipeline = Pipeline(
        technique_family="vibrational",
        steps=[
            PipelineStep(name="crop", params={"min_x": 450, "max_x": 1800}, step_id="crop"),
            PipelineStep(name="baseline", params={"method": "asls", "lam": 1e6, "p": 0.01}, step_id="base"),
            PipelineStep(
                name="spectral_integrations",
                params={"windows": [{"id": "band1", "min_cm1": 1050, "max_cm1": 1110, "mode": "signed"}]},
                step_id="int",
            ),
        ],
    )

    # 3. run it on every spectrum and wait
    session = client.sessions.create(SessionCreateRequest(dataset_id=ds.dataset_id, pipeline=pipeline))
    run = client.analysis.create_run(
        AnalysisRunCreateRequest(
            dataset_id=ds.dataset_id,
            session_id=session.session.session_id,
            subset=SubsetStrategy(kind="all"),
            async_=True,
        )
    )
    client.analysis.wait_for_analysis_job(run.job_id, timeout_s=600)

    # 4. export the observation table (features + labels + axes)
    client.analysis.export_observation_to_file(run.run_id, "run42_observation.csv")

    # 5. statistics on the finished run
    pca = client.explore.pca(PCARequest(analysis_run_id=run.run_id, scaler="standard", n_components=3))
    print(pca.explore_id)
The easiest way to write a pipeline is to build it in the web interface and use Export current pipeline: the JSON file contains exactly the steps structure used above. The server's list of step names and parameters is at /meta/pipeline-steps (and Pipeline steps A–Z).

Useful calls

TaskCall
List datasets / pipelinesclient.datasets.list(), client.pipelines.list()
Export / import a dataset packageclient.datasets.export_to_file(id, path), client.datasets.import_package(path)
Features only, long format, Parquetexport_features_to_file, export_observation_to_file(..., layout="long"), (..., format="parquet")
Manifest of a runclient.analysis.export_manifest(run_id)
Fit curves for figuresclient.analysis.create_fit_curve_job(...), wait_for_fit_curve_job, export_fit_curve_job_to_file
Spectrum matrix and FPCAclient.explore.create_matrix_job(...), fpca_discrete, spectrum_cluster
Whole-column inspectionclient.analysis.observation_columns(run_id, ...)

Practical notes

  • Runs are asynchronous: wait for the job, as above. Only one run executes at a time on the server.
  • The same reproducibility advice applies: save the pipeline JSON and the run manifest next to your results.
  • Errors raise from httpx with the server's message; the interactive API reference at /docs shows every field.
  • An AI assistant can do all of this for you through MCP.
