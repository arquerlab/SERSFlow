Alignment & Resampling

Interpolates every spectrum onto a common x grid.

  • min_x / max_x: grid bounds. Defaults are 400 and 2000; change them for your data (and for XPS).
  • grid_mode: step (with step, default 1.0) or points (with n_points, default 512).
  • interp: linear or cubic (cubic falls back to linear for fewer than 4 points).

Outside the measured range the edge value is held flat (not empty). A descending axis comes out ascending. Needed before Outlier Detection and before a spectrum matrix in Analyze, which require identical grids.

Baseline Correction

Subtracts an estimated slowly varying background. Choose a category, then a method, then its parameters. Full list: Baseline methods.

Cosmic Ray Removal (vibrational only)

Finds narrow spikes and replaces them by interpolation.

  • method: zscore (threshold 5, window 5) or derivative (threshold 3, window 3). Switching resets the settings below.
  • interpolation: median (default), linear, cubic. max_width (10 points): wider features are never treated as spikes. min_intensity_ratio (2.0): spike height relative to local background. n_iterations (3).
Run it before baseline subtraction: spots with zero or negative local background are never corrected. Use an odd window. With very fine sampling, narrow genuine bands can be mistaken for spikes: lower max_width or raise the threshold.

Cropping

min_x, max_x: keep only points in this inclusive range. A new Cropping step starts empty: fill both fields. Crop first, to the region you trust.

Derivative

order (default 1): repeated numerical gradient. It amplifies noise, so smooth first.

Aggregate Spectra

Combines spectra of the cohort into aggregated spectra. Steps above it run on every spectrum first (baseline, calibration, normalization...); steps below it run on the averages. Aggregating after baseline correction is not the same as aggregating raw spectra, so place the step where you want it.

  • method: all (one average), by label (spectra sharing the values of group by: tick one or more labels from the dataset, e.g. current_density, sample), or by range (bins of range width on a numeric or timestamp label chosen under range label, e.g. every 300 s on time_s, or 20 on acquired_at; range origin empty starts at the smallest value).
  • split by region (default on): never mixes XPS regions; C1s and O1s always give separate averages.
  • reducer: cumulative (default, the sum of the members), mean or median. min group size drops groups with fewer members.
  • Each aggregated spectrum is a registered spectrum (role group_mean) with a stable id: same dataset, grouping rule and group key give the same id on every rerun, whatever the upstream steps. Its labels keep the grouped values, give numeric labels as mean plus _min/_max (mixed for differing text), and add n_averaged and the member ids.
  • Subset preview: views before this step show the subset's own spectra; views at or after it show the aggregated spectrum of every group a subset spectrum belongs to (built from the whole group, not just the sampled members). Several subset spectra in one group give one aggregate.
  • Members with different x axes are interpolated onto the first member's axis (overlap only).
Steps below the group cannot point back at steps above it (Input = After step, or a Normalization baseline step); the run stops with an error. Fitting or intensity steps above the group are ignored for the aggregated spectra.

Low-Signal Filter

Removes whole spectra that are too weak (dead acquisitions).

  • metric: mean, median (default), integrated, maximum intensity, or intensity percentile (with percentile, default 10).
  • threshold: spectra whose metric is below it are removed. The default 0 removes nothing.
  • A histogram shows the distribution with the threshold as a dotted red line; hover a bar to overlay up to 12 of its spectra. “Affected: n / total” updates live.
The action menu (exclude/flag) has no effect: spectra below the threshold are always excluded. The metric is computed on the output of the steps above, so position matters; place the filter just after Cropping.

Metadata Filter

Keeps only spectra whose labels match, on this branch: others become empty and later steps ignore them. It does not delete them from the dataset. Use Input = Initial on a later filter to start again from everything (for example one branch per XPS region).

  • Add filter: choose a label (Filter by), then tick values (categorical) or choose an operator (=, !=, >, >=, <, <=) and a number.
  • Several values in one row = OR; several rows = AND. No filters = everything passes.

Normalization

method: max (default), min, mean, median, vector (L2), spectrum point (divide by the intensity at point_x, default 1000), baseline point (divide by the baseline value at point_x, needs an earlier enabled Baseline step chosen under “baseline step”).

  • Use max for overlays, vector (L2) for PCA and clustering, spectrum point on an internal-standard band for quantification.
  • Normalize after baseline and spike removal. A zero denominator is silently replaced by 1; min/mean/median can be near zero on baseline-subtracted data.

Outlier Detection

Removes whole spectra that look unlike the rest. Needs identical x grids: add Alignment & Resampling above it.

  • correlation to median (default): removed if Pearson r to the median spectrum is below the threshold (start at 0.9–0.98). Lower r = more anomalous.
  • PCA reconstruction error and PCA score-space distance: removed if the score is above the threshold; extra settings PCA scaler (none/standard) and n_components (8). Thresholds are in raw score units; read them from the histogram.
  • As with the Low-Signal Filter, the action menu is ignored: outliers are always excluded. Normalize first, and inspect the hovered overlays before tightening.

Reference Transformation

Subtracts or divides every spectrum by a reference spectrum (blank, solvent, substrate).

  • reference file: a spectrum of the active dataset.
  • operation: subtract reference or divide by reference (division by near-zero gives empty values).
  • reference stage: Raw data or After step N. The reference goes through the same pipeline up to that step, then is interpolated onto each spectrum. To subtract a processed blank, choose the stage that matches your sample processing. N counts enabled steps only.

The reference spectrum itself is excluded from the analysis and exports.

Smoothing

Savitzky–Golay: window_length (odd, default 11) and polyorder (default 3, must be smaller than the window). A window longer than the spectrum, or polyorder not below the window, silently leaves the spectrum unchanged. Choose a window of about a third of the narrowest peak's width in points; over-smoothing broadens peaks and biases fitted widths.

XAS Edge Normalization (XAS only)

Subtracts a polynomial pre-edge line and divides by the edge step (post-edge minus pre-edge, both evaluated at E0), so the pre-edge sits at 0 and the post-edge at 1.

  • E0: empty = the steepest rise of the spectrum. Set it by hand on noisy signals (e.g. partial-yield counts), because the automatic pick can land on noise.
  • pre-edge / post-edge from–to: empty = automatic windows (lower 60 % of the range below E0, upper 50 % above it). Windows are clipped to the data and must hold enough points for the chosen degrees.
  • flatten also removes the post-edge slope above E0.
  • Only offered for XAS datasets. Normalize after smoothing and any x-axis calibration.

X-axis Calibration

Shifts the x axis (x_new = x + shift).

  • fixed offset: add offset to every x value.
  • single reference band (and the legacy “reference peak”): fit a reference band in selected spectra, average its position and apply one shift so it lands on target_x (default 284.8 eV for XPS) for all spectra. Choose reference spectra with Add reference filter. With no filter, every spectrum is a reference. If nothing matches or the fits fail, the shift is 0 with only a warning.
  • grouped reference band: group by a label (for example sample or potential) and calibrate each group separately. reference mode core level shifts all spectra of a group by the offset measured on the first spectrum of the reference region (for example C1s) in that group; valence band shifts each core region by its own valence-band partner's Fermi edge (target 0 eV).

Reference modes need an earlier, enabled Peak Fitting step (choose it under “fitting step”) and the fitted position (position / center key). Use a simple one- or two-peak model for the reference fit and check its residual first. Typical choices: C 1s adventitious at 284.8 eV; Fermi edge at 0 eV.

The preview “After: fitting” runs the earlier steps on the whole cohort, so valence-band partners are available.
