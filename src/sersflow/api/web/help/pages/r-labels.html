Labels and file naming

Labels describe each file: sample, pH, gas, potential, laser settings and so on. SpecFlow reads them from your file names and folder names using fixed rules, and you can then correct them by hand.

Name your files for automatic labels

The text searched is the file name (without extension) plus up to three parent folder names, so a folder called pH2 or K2SO4 can supply labels too. Matching is case-insensitive and tokens are separated by underscores. A decimal point can be written ., d or _: 0d5, 0.5 and 0_5 all mean 0.5.

LabelWrite it asExamples
sampleThe first underscore-separated words of the file name, up to the first recognised setting.CuAq_785nm_… → CuAq; Cu_300_… → Cu_300
gasAr, O2, N2, CO2, 12CO2 (→ CO2), 13CO2…_CO2_…
phpH + numberpH2, pH_6d8, pH7.5
laser_nmThree digits + nm785nm, 532_nm
laser_power_pctNumber + % or p50%, 0d05p (0.05 %)
current_density_A_cm2Number + uA, mA or A; stored in A·cm⁻²-1mA, 0_50_mA_cm2, -5uA
potential_V, potential_refNumber + reference-0d8VRHE or -0d8RHE → VRHE;
-0d5VAgAgCl → converted to VRHE (needs pH in the name);
-0d365V → ref “V” (no reference assumed);
OCP → 0.0, ref “OCP”
electrolyte, concentration_MConcentration + compound, in either order0d1M_KHCO3, KHCO3_0d1M, 10mM_KOH (converted to molar). Bare KHCO3, K2SO4, H2SO4, KOH are recognised without concentration.

A complete example:

CuAq_785nm_0d05p_2s_25aqq_-0d05VRHE_-1mA_1M_KHCO3_pH2_CO2_map.txt
→ sample CuAq · 785 nm · 0.05 % · −0.05 VRHE · −0.001 A/cm² · KHCO3 1 M · pH 2 · CO2
  • The token OCP also sets the current density to 0.
  • A trailing number after a dash in a name, like -3 or -3-6, is treated as a repeat counter and removed. That also affects a folder named pH-13: write pH13 or pH_13 instead.
  • Labels that are not recognised stay empty. Always check the summary shown next to each file.

XPS files

For VAMAS and NeXus files, every region (block) gets its own structural information (region name, average or individual, pass energy, excitation energy, replicate number) plus experiment labels read from the path and from the block name and comments. For VAMAS, the block's sample identifier string is kept as sample and is also searched for gas, pH, current, potential and electrolyte. Block labels take priority over labels from the path.

Editing labels by hand

  1. Tick the file (or the block row, for XPS) you want to change. The Edit labels panel shows its labels.
  2. Type new values in the table. Fixed rows are: acquired_utc (read-only), sample, gas, ph, current_density_A_cm2, potential_V, potential_ref, laser_nm, laser_power_pct, electrolyte, concentration_M.
  3. For your own label, press Add custom row and type a key and value (Remove last custom row undoes it). Custom rows are available when editing a single file.
  4. Press Save (one item) or Apply to N files / Apply to N blocks. Only the cells you changed are sent.

How values are interpreted

  • Empty cell → stored as empty (null).
  • true / false → yes/no.
  • 2 or 0.5 → a number. Text in double quotes → text. If the cell cannot be read as a number or JSON it is kept as plain text.
  • A sample called 300 becomes the number 300. Type "300" with quotes to keep it as text.

Editing many files at once

The editor follows the last file you ticked. To edit several files together, first select many (use a folder checkbox or Select all), then untick one file; the panel switches to “Bulk edit mode for N files”. In bulk mode the table starts blank and only the cells you fill are written. You cannot mix files and XPS blocks in one edit.

Reload auto labels

Reload auto labels re-reads the names and replaces the stored labels. Your hand-edited values and custom rows are lost, and so are hand-edited block labels in XPS files. Use it only to start over.

Units: current density is stored in A·cm⁻² (1 mA·cm⁻² = 0.001). Potential references used are VRHE, OCP, V and VAgAgCl.
