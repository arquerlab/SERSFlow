Tutorial 3 · XPS: fit and compare

Goal: fit the O 1s region at several potentials, compute the hydroxide fraction and see how it changes. Continues Tutorial 2.

⏱ about 35 minutesLevel: intermediateData: the sample XPS files, or your own region

Before you start

  • You have the sample XPS files uploaded and know the charging shift from Part 2 (about −0.65 eV).
  • The sample O 1s spectra contain a lattice oxygen peak, a hydroxide peak whose share grows with potential, and a small water peak. As measured they sit 0.65 eV too high (near 530.45, 532.05 and 533.65 eV); after calibration they are at 529.8, 531.4 and 533.0 eV.

1. Create the O 1s dataset

  1. Prepare → tick the eight O 1s files, name the dataset xps_O1s, Create dataset, then Create subset.
  2. Pipeline type should show XPS.

2. Calibrate with the offset you measured

  1. Add + X-axis Calibration, method fixed offset, offset −0.65.
  2. View → After: x_axis_calibration: the main O 1s peak should now be near 529.8 eV.
Using a measured offset on another region is only valid if both regions charged the same way. For real samples, check against a second reference (Fermi edge or another core level).

3. Choose the background (one, not both)

For this tutorial use the active background inside the fit. Do not add a static Shirley baseline step as well: SpecFlow refuses to save a pipeline with both. See Backgrounds: static or active.

4. Fit O 1s

  1. Add + Peak Fitting. Region / band: O1s. Fit window: 526 to 536 eV.
  2. Add a Shirley background (active) component.
  3. Add three GL components with these Peak names and centres (bounds ±0.7 eV; FWHM 1.3, bounds 0.5–3; m 30; amplitude Auto):
    Peak nameCentre (eV)Meaning
    lattice529.8Metal–oxygen
    OH531.4Hydroxide
    H2O533.0Adsorbed water (small)
  4. View → After: fitting → Run preview plot (subset). Check the residual of several spectra.
Three peaks and a smooth background follow the data; the residual looks like noise. The OH peak is larger at higher potential than at 0 V.
Own data with a recipe

For real regions, try the recipe picker (Fitting recipes): search the compound, select your pass energy, choose Replace. Then adjust centres, bounds and links. For doublets, set the FWHM link to equal and the position link to offset by the spin–orbit splitting.

If a fit fails the spectrum passes through unchanged and its fit columns end up empty. You will check this in step 7.

5. Derive a metric

Add + Metric Calculation: id oh_frac, formula:

{fit_O1s_OH_area}/({fit_O1s_lattice_area}+{fit_O1s_OH_area}+{fit_O1s_H2O_area})

The variable list may show these names slightly differently (see the caution on Metric Calculation). If the metric is empty after the run, compare with the real column names in the exported table.

6. Save and run

  1. Name the pipeline xps_O1s_v1: Save to library, Save pipeline.
  2. Analyze → dataset xps_O1s and that pipeline → Run feature extraction (async) → wait for completed.

7. Check the fits, then compare

  1. Plots → Fit diagnostics: choose the fitting step, tick several spectra (up to 10). Look at RMSE, R² and the residuals. A failed fit would show an error here.
  2. Plots → Parameter vs parameter: X = meta_potential_V, Y = op_oh_frac, style Line.
  3. Exports → Fitting curves → data + fit + components + residuals → All PNG zip for figures; Observation wide CSV for the table.
The hydroxide fraction rises from about 0.25 at 0 V to about 0.7 at 1.4 V: the trend built into the sample data.

What you learned

  • XPS needs the right order: calibrate, then fit.
  • Choose one background strategy.
  • Name your peaks: the names end up in every result column (fit_O1s_OH_area).
  • Always check fits (Fit diagnostics) before trusting numbers.
