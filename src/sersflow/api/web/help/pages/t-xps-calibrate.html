Tutorial 2 · XPS: load and calibrate

Goal: bring XPS spectra into SpecFlow and correct the charging shift of the binding-energy axis so the C 1s reference peak sits at 284.8 eV. Part 2 (fit and compare) continues from here.

⏱ about 25 minutesLevel: intermediateData: your VAMAS/NeXus file, or the sample set below

Before you start

Sample data (recommended to learn)

Synthetic C 1s and O 1s spectra of a NiFeOx film at eight potentials, saved as text files. The sample sits about 0.65 eV too high because of charging.

⬇ Download sample XPS files (zip)
Your own data

A .vms (VAMAS/CasaXPS) or .nxs (NeXus) file with several regions. Boxes marked “VAMAS / NeXus” show what differs.

Text files carry only one spectrum each and no region name; the file name supplies the sample and potential (NiFeOx_pH13_0d4VRHE_C1s.txt). Their first header cell must be “Binding energy” (or “BE”) so that SpecFlow knows it is XPS.

1. Upload and inspect

  1. Uploads → upload the files (all sixteen text files, or your VAMAS/NeXus file).
  2. Check the labels: sample NiFeOx, ph 13, and potential_V from 0 to 1.4 with potential_ref VRHE.
  3. Raw visualization → select a file. The x axis is binding energy.
A C 1s file shows one strong peak near 285.4 eV (284.8 + 0.65 charging) with small shoulders at higher binding energy.
VAMAS / NeXus: each file holds many regions

Expand the file row to see blocks such as “C 1s — OCP”. In Raw visualization the first region's averaged spectra are drawn; change the block filter to look at others. Correct block labels by ticking the block rows (not the file) in Uploads.

2. Create the dataset

  1. Prepare → in Create new dataset, tick the eight C 1s files only (their names end in _C1s). Name it xps_C1s and press Create dataset.
  2. The pipeline type becomes XPS automatically (a dataset cannot mix XPS and vibrational files).
  3. Press Create subset and set View to Raw (subset) to see the uncorrected peaks.
All peaks sit around 285.4 eV rather than 284.8 eV.
VAMAS / NeXus: select a region

Use the XPS region menu, the Regions dropdown or tick block rows; a whole-file tick keeps averaged spectra only. Then add + Metadata Filter with Filter by xps_region = C 1s so later steps work on one region. See datasets.

3. Fit a reference peak

The calibration step measures the position of a reference band by fitting it, so the pipeline needs a Peak Fitting step first.

  1. Add + Peak Fitting. Set Region / band to C1s.
  2. Use a simple model: one Gaussian-Lorentzian (GL) peak, Peak name CC, centre 284.8, FWHM about 1.2 with bounds 0.3–3, m 30, amplitude Auto, and centre bounds 282–288 so the fit can find the shifted peak. (Or choose the “C 1s adventitious” recipe and keep only its main peak.)
  3. Set the Fit window from 282 to 290 eV so the shoulders do not distort the reference.
  4. View → After: fitting and press Run preview plot (subset).
The fitted GL peak (blue/orange) follows the main peak at about 285.45 eV; the residual is small near the peak.

4. Calibrate the axis

  1. Add + X-axis Calibration after the fit.
  2. Input XY for this step: choose Initial (or the step before the fit). A fitting step replaces the spectrum with the fitted curve; with this setting the shift is applied to your data, not to the model.
  3. Set method to single reference band, fitting step to your fit, position key to the …_CC_pos entry, and target_x to 284.8. Leave the reference filters empty: every spectrum is a reference, their fitted positions are averaged and one shift is applied to all.
  4. View → After: x_axis_calibration and Run preview plot (subset).
All peaks now sit at about 284.8 eV (within a few hundredths of an eV). The shift applied was about −0.65 eV.
If nothing matches the reference filters or the reference fit fails, the shift silently becomes 0 (only a warning is logged). Always look at the result with the “After:” view.
VAMAS / NeXus: calibrate each group separately

When different measurements charge differently, use grouped reference band: set group by to the label that identifies a measurement (sample, potential…), reference mode core level and reference region C1s. In each group the first spectrum of that region is fitted and its offset is applied to every spectrum of the group. Spectra without a region label cannot be grouped this way, which is why the sample text files use single reference band. Valence-band mode shifts each core region by its Fermi-edge partner (target 0 eV). Details: X-axis Calibration.

5. Save

Keep the reference fit and the calibration for later: type a name such as xps_C1s_cal and press Save to library and Save pipeline. Note the shift you found (about −0.65 eV): you will apply the same offset to the O 1s data in Part 2, because both regions were measured on the same charging sample.
