FAQ

General

Where is my data stored?

On the machine running the SpecFlow server: uploads in .sersflow_uploads/, durable dataset copies in .sersflow_data/, large outputs in .sersflow_artifacts/, metadata in sersflow.db.

Does Prepare change my data?

No. A pipeline is a recipe applied on the fly; your raw files and datasets stay untouched. Results exist only as analysis runs and exports.

Why are previews limited to 30 spectra?

To keep them fast. Preview plots use a random subset (at most 30 spectra). The Analyze run always uses every spectrum.

Do I need to press Save pipeline?

Previews save automatically to the session, but press Save pipeline before going to Analyze, and Save to library to keep a named copy.

Uploading and labels

Can I upload a whole folder?

Yes, with the folder picker. Sub-folders are kept, and folder names can supply labels (for example pH2).

My labels are wrong. What now?

Tick the file and edit the cells in Edit labels, then Save. For many files, select many then untick one. See Editing labels by hand.

How do I add my own label, like “batch”?

Edit one file, press Add custom row, type a key and value, Save. It appears as meta_batch in exports.

Can I mix Raman and XPS files in one dataset?

No. Create one dataset per technique.

Pipelines

Why does my normalization or integration look wrong after a fit?

A Peak Fitting step replaces the spectrum with the fitted model. Put steps that need the data before it, or give them Input XY = Initial / After step K.

What is the difference between Save pipeline and Save to library?

Save pipeline writes the editor to the current session (what Analyze uses). Save to library stores a named copy that you can reuse on other datasets and share.

I picked a saved pipeline and lost my edits.

Choosing from the Saved menu loads immediately and discards unsaved edits. Save your edits first, under a new name.

Can I run the same pipeline on a different dataset?

Yes, if the technique matches. Select the dataset, then load the pipeline from the library.

My fit failed but there is no error.

A failed fit lets the spectrum pass through unchanged; its fit columns are empty and gof_success is 0. Check Plots → Fit diagnostics after a run.

Analysis and exports

How long does a run take?

From seconds (tens of spectra) to many minutes (tens of thousands, with fits). Only one run executes at a time on the server; others wait as pending.

Where is the file name in the export?

The observation table has no file-name column. Put what you need into a label (sample, batch…). The PCA scores CSV includes the file path.

How do I get error bars?

In Plots → Parameter vs parameter choose Mean ± error bars (group by X): the bars are the standard deviation of replicates with the same X, or supply an error column.

Can I keep my PCA results?

Download the CSVs right away. The server keeps one PCA result per run; running again overwrites it. Results are also lost from the page on reload.

AI assistants and Python

Can an AI assistant use SpecFlow?

Yes, through the MCP server. See Tutorial 6 and MCP server: setup.

Can I script SpecFlow?

Yes: Python client, or call the HTTP API directly (see /docs).

Is anything sent to the internet?

SpecFlow runs locally. The page loads the Plotly library from a CDN. If you use an AI assistant through MCP, what the assistant sees depends on that service; the MCP server returns ids, summaries and file paths rather than full tables.

Help itself

How do I link to a Help page?

Copy the address from the browser: it ends in #help/<page>/<section>. Anyone with access to your SpecFlow server can open it.

How do I print a page?

Ctrl+P (or Cmd+P) prints only the page you are reading; choose “Save as PDF” to make a file.

I found a mistake or something out of date.

The pages are plain HTML in src/sersflow/api/web/help/pages/. The footer of each page shows which version it was reviewed against.
