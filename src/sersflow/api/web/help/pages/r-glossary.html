Glossary

Active background
An XPS background (Shirley, Tougaard, slope) fitted together with the peaks inside a Peak Fitting step. Opposite: static baseline.
Analysis run
One execution of a pipeline over the whole dataset (Analyze → Run feature extraction). Produces a feature table. Statuses: pending, running, completed, failed.
Baseline
Slowly varying background (fluorescence in Raman, inelastic background in XPS) that is estimated and subtracted.
Batch mode
Prepare mode that works on the full dataset (quick metrics) instead of previewing a subset.
Block
One region/spectrum inside a multi-spectrum XPS file (VAMAS, NeXus).
Dataset
A named collection of spectra of a single technique, built from uploads and stored durably.
EVR
Explained variance ratio: the fraction of total variance captured by a principal component.
Feature
A number extracted per spectrum (intensity, area, fitted position…). One column in the results.
FPCA
Functional PCA: PCA on whole spectra treated as curves. “Discrete” does PCA on the matrix; “FDA” uses a functional-data library.
FWHM
Full width at half maximum of a peak.
Label
A piece of metadata about a file (sample, pH, potential…). Appears as meta_* in exports.
Library (pipelines)
The shared list of saved, named pipelines.
Manifest
JSON record of a run: ids, pipeline hash, feature list, file format.
MCP
Model Context Protocol: a standard that lets an AI assistant call SpecFlow's functions as tools.
Observation table
The main export: one row per spectrum with features, axes and labels.
Pass energy
XPS analyser setting; determines peak widths and selects the matching recipe width.
PCA / sparse PCA
Principal component analysis; the sparse version forces most loadings to zero for easier reading.
Pipeline
An ordered list of processing and feature steps.
Recipe (XPS)
A packaged starting point for fitting a known chemistry, with peak types, positions, widths and bounds.
Region (XPS)
The core level or band a spectrum belongs to, such as C1s or O1s.
Session
The working pipeline and subset attached to a dataset in Prepare. Created automatically.
Subset
A few random spectra used only for preview plots.
Technique family
“Vibrational” (SERS/Raman/FTIR) or “XPS”. Datasets and pipelines each have exactly one.
Upload
A raw file stored on the server.
VIF
Variance inflation factor: how well one feature is explained by the others. Above about 5–10 means collinearity.
