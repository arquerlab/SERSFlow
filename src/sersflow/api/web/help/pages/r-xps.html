XPS specifics

Everything that works differently for X-ray photoelectron spectroscopy: data handling, calibration, backgrounds, recipes and links.

Data

  • Load .vms (VAMAS/CasaXPS) or .nxs (NeXus) files. Each region is a block; the dataset keeps the region name for every spectrum.
  • A whole-file selection keeps the averaged spectra only. Tick block rows to include replicates (datasets).
  • Choose XPS as pipeline type (automatic when the dataset is XPS). A dataset cannot mix XPS and vibrational files.
  • Use a Metadata Filter on xps_region to work on one region, and use Input = Initial for a second branch on another region.

Charge correction (X-axis Calibration)

  • Adventitious C 1s at 284.8 eV (the editor's default target), or the Fermi edge at 0 eV for metals.
  • Use grouped reference band with group by the label that distinguishes measurements (sample, potential…), and reference mode core level or valence band.
  • The calibration needs an earlier enabled Peak Fitting step to measure the reference position.
  • Details: X-axis Calibration.

A static Shirley/Tougaard baseline and an active Shirley/Tougaard background cannot be enabled at the same time. A red banner appears, saving is refused and the server returns an error. Applying a recipe with “Replace” adds an active Shirley background, so remove or disable the static baseline step first. (The slope background is not covered by this check: do not combine it with another background by accident.)

Fitting recipes

A recipe pre-fills the Peak Fitting editor for a known chemistry (for example “C 1s adventitious” or a metal oxide) with peak types, positions, widths and bounds taken from the packaged tables.

  1. In the Peak Fitting editor, find XPS fitting recipe. Filter by element chips or type into the box (for example C 1s or NiO).
  2. Choose the Pass energy (eV) that matches your measurement; widths come from the table for that pass energy.
  3. Pick a recipe. If the editor already has peaks, SpecFlow asks whether to Add (new peaks only, no extra background) or Replace (everything, including an active Shirley background).
  4. The recipe turns on amplitude Auto and fills “Initial area ratios”. Check Warnings under the picker for provenance notes.
  5. Preview with View → After: fitting, then adjust positions, bounds and links.
  • Positions get bounds of about ±0.5 eV or more; widths have an upper bound of at least 8 eV; amplitudes are not negative.
  • Spin–orbit doublets are seeded 2:1 in area but not locked. Add Links if you want them tied.
  • “Active recipes” lists the base and added recipes; Remove drops one. Fermi-edge recipes give a single Fermi-edge component.

Links for doublets

Example for a 2p doublet: set the 2p1/2 peak's FWHM link to equal to the 2p3/2 FWHM, and its pos link to offset by the spin–orbit splitting. Use scale with care: on amplitude it fixes a height ratio, not an area ratio.

XPS safeguards

Widths without an upper bound are limited automatically, and if all peak amplitudes look tiny compared to the data (as with seeds near 1) they are rescaled. You still must place peak centres sensibly: they start at 1000 unless a recipe sets them.

XPS results

Column names include the region, for example fit_C1s_p1_pos, fit_C1s_p1_area and fit_C1s_gof_r2. Use Metric Calculation for ratios such as the area of one component over a total (metrics).
