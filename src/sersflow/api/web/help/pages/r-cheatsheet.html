The workflow

  1. Uploads → upload files, check labels.
  2. Raw visualization → look at the data.
  3. Prepare → Create dataset → Create subset → build pipeline → Save to library + Save pipeline.
  4. Analyze → pick dataset + pipeline → Run feature extraction → wait for completed → statistics and exports.

Default step order

SERS / RamanXPS
Cropping → Cosmic Ray Removal → Smoothing → Baseline Correction → Normalization → Peak Integration / Peak Fitting → Metric CalculationMetadata Filter (region) → Peak Fitting (reference) → X-axis Calibration → Peak Fitting (analysis, active Shirley) → Metric Calculation

A fitting step replaces the spectrum with the model: put anything that needs the data (integration, normalization) before it.

Good first values

StepStart with
CroppingFill both limits (new steps start empty)
Cosmic Ray Removalzscore, threshold 5, window 5 (odd); run before the baseline
Smoothingwindow 11, polyorder 3 (about a third of the narrowest peak)
Baselineasls, lam 1e6, p 0.01
Normalizationmax to look, vector (L2) for PCA
Outlier Detectioncorrelation to median, threshold 0.9–0.98 (needs Alignment & Resampling above)
X-axis Calibration (XPS)C 1s at 284.8 eV, Fermi edge at 0 eV

Labels from file names

sample_785nm_1p_2s_pH7_-0d3VRHE_0d1M_KHCO3_CO2.txt → laser 785 nm, power 1 %, pH 7, −0.3 VRHE, 0.1 M KHCO3, gas CO2. Decimal point = d, . or _.

Remember

  • Hide ≠ delete; Purge is permanent.
  • Datasets are single-technique (vibrational or XPS).
  • The Pipeline “Saved” menu loads immediately and discards unsaved edits.
  • PCA defaults to PC2 vs PC3; k-means ignores scaling; re-running PCA overwrites the previous one.
  • Max 50 runs per dataset are kept; download what you need.
  • Press / in Help to search.
