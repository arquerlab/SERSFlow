Start here: how SpecFlow works

SpecFlow turns raw spectra (SERS, Raman, FTIR and XPS) into clean, reproducible feature tables and statistics. You work through four tabs, left to right.

The workflow in one picture

TabWhat you do thereResult
UploadsDrop in your instrument files; check and edit the labels (sample, pH, potential, laser…).Files stored on the server, with metadata.
Raw visualizationLook at the raw spectra, series heatmaps and maps before touching anything.A feel for your data.
PrepareGroup uploads into a dataset, then build a pipeline (crop, despike, smooth, baseline, normalize, fit peaks…) and preview it on a random subset.A saved pipeline.
AnalyzeRun the pipeline on the full dataset, then explore: correlations, PCA, clustering, heatmaps, exports.Feature tables, figures and CSV/Parquet files.

Five ideas worth knowing

Upload
A raw file on the server. Uploading does not parse the spectra; it only stores the file and reads labels from the name and path.
Dataset
A named, durable collection of spectra built from one or more uploads. A dataset has one technique, either vibrational (Raman/SERS/FTIR) or XPS; mixing the two is rejected.
Pipeline
An ordered list of steps. Python owns the science: the step list and defaults come from the server, so the UI always matches the backend. Pipelines can be saved to a shared library and reused.
Subset (preview) vs. full dataset (batch)
In Prepare, plots use a small random subset so they stay fast. Nothing is computed on the whole dataset until you start a feature extraction run in Analyze.
Analysis run
One execution of a pipeline over the full dataset. It runs in the background and must reach completed before exports and statistics become available.

How this guide is organised

  • Tutorials are task-based: follow the numbered steps in order. Green “You should see” boxes tell you what to expect.
  • Quick help: a cheat sheet, which method to use and an FAQ.
  • Reference manual pages describe every control. Tutorials link to them with “Reference” notes.
  • Words in this style are buttons, tabs or fields exactly as they appear on screen.

Three ways to use SpecFlow

  1. The web interface (this page): everything in these tutorials.
  2. An AI assistant through the MCP server: describe the analysis in plain language and the assistant drives SpecFlow for you. See Tutorial 6.
  3. Python scripts through the HTTP client (SersflowClient): see Python client.
Your data stays on the machine that runs the SpecFlow server. Uploads are stored under .sersflow_uploads/, durable dataset copies under .sersflow_data/ and large outputs under .sersflow_artifacts/.
