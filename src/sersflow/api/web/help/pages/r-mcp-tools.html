MCP server: tools and safety

Tool names mirror the web API: get_… reads, post_… creates or runs, put_… updates a session. The tools return short summaries and file paths, never whole tables.

Read-only resources

Six resources are offered, for example sersflow://pipelines (saved pipelines) and sersflow://openapi/summary. Many clients require you to attach resources by hand; the tools cover the same ground.

Running things: the job pattern

  1. Start with post_analysis_runs (or post_explore_matrix_jobs). You get a run_id and a job_id.
  2. Wait with post_analysis_jobs_wait, or look with get_analysis_jobs.
  3. When the status is completed, export or explore.
The wait tools allow up to 3600 s by default, longer than most clients tolerate. Ask the assistant to pass a short timeout_s (30–60) and call again. A timeout is not a failure: the reply is {"error":"timeout","resume":{…}} and tells it what to call next.

Saved pipelines and runs

pipeline_id and pipeline_name given to post_analysis_runs or post_explore_matrix_jobs are labels only. To run a saved pipeline, either fetch it with get_pipelines_by_id and pass it inline (with a subset such as {"kind":"all"}), or create a session from it first with post_sessions.

Confirmation gates

When a guarded action is requested, the tool refuses with needs_confirm: true and a message. The assistant must show you that message and repeat the call with confirm=true only after you say yes.

Guarded actionCondition
Purge uploadsAlways.
Upload, dataset import, plot outputLarger than 100 MiB (upload_confirm_bytes).
Create/run/save a pipelineA fitting step has more than 20 components (fitting_confirm_max_components).
Write outside the export folderAbsolute output_path not inside export_dir.

Things that surprise people

  • Fixed file names overwrite. Default output names such as plot_spectrum.json are fixed. Ask the assistant to give each export its own output_path.
  • XPS recipes replace. Applying a recipe to a session replaces any existing fitting step for the same region.
  • Reading values. The assistant should read a CSV only when a number is needed. If it passes an explicit max_rows, the default cap does not apply.
  • No prompt templates are shipped; the examples in Tutorial 5 work as plain prompts.

Error messages

You seeMeaning and fix
“API requires authentication…”Add SERSFLOW_USERNAME and SERSFLOW_PASSWORD to the client's env, or use SERSFLOW_AUTH_DISABLED=1 locally.
“SpecFlow API not reachable…”Wrong SERSFLOW_URL, or api_start_enabled = false. Start sersflow-api.
“Timed out waiting for API health” / “exited early”Read api_spawn.log in the export folder: port busy, slow first start (raise api_health_timeout_s), or auth enabled without SERSFLOW_AUTH_SECRET.
“MCP config not found”SERSFLOW_MCP_CONFIG points to a missing file.
