Tutorial 2 · XPS: calibrate, fit, compare

Goal: from a multi-region VAMAS or NeXus file to fitted peak areas for one region (here C 1s and O 1s), compared across conditions. About 40 minutes.

You will need: a .vms, .nxs or .nx5 file. Conditions (potential, current…) can be in the block names or file path; see Labels.

1. Upload and inspect

  1. Uploads → upload the file. Each file row shows the number of spectra (blocks); expand it to see rows such as “C 1s — OCP”.
  2. Check the labels of a few blocks (sample, potential_V, current_density_A_cm2…). Correct block labels by ticking the block rows (not the file) and saving.
  3. Raw visualization → select the file. By default the first region's averaged spectra are drawn; change the filter to look at others. The x axis is binding energy.

2. Create an XPS dataset

  1. Prepare → in Create new dataset, tick the file (this keeps the averaged spectra). To take only some regions, use the XPS region menu or the Regions dropdown, or tick block rows.
  2. Name it (for example xps_insitu) and press Create dataset. The pipeline type switches to XPS.
  3. Use Create region subset with C 1s to preview only that region.

3. Select one region

Add + Metadata Filter: Filter by xps_region, tick C 1s. Everything after this step works on C 1s only. (Later, add another Metadata Filter with Input = Initial to start an O 1s branch.)

4. Fit a reference peak and calibrate the axis

Charge correction needs a fit of a reference band first, so the order is: fit, then calibrate.

  1. Add + Peak Fitting. Set Region / band to C1s. In the recipe picker choose C 1s adventitious, select your Pass energy and Replace.
  2. View → After: fitting. Check the fit and residual of several spectra.
  3. Add + X-axis Calibration after this reference fit (it needs an earlier fitting step to measure the peak). Because a fitting step replaces the spectrum with the fitted curve, set the calibration's Input XY for this step to After step K where K is the step before the reference fit (for example the Metadata Filter). Then the shift is applied to your data, not to the fitted curve. The fits for your actual analysis come after the calibration (step 5).
  4. In X-axis Calibration choose grouped reference band, fitting step = your first fit, position key = the main C 1s peak position, target_x = 284.8, group by = the label that identifies each measurement (sample or potential), reference mode = core level, reference region = C1s.
  5. View → After: X-axis Calibration: the C 1s main peak should now sit at 284.8 eV in every group. Remember that a failed reference fit gives a shift of 0 with only a warning, so verify.
If the dataset has the same reference measured for every spectrum (one sample), single reference band is simpler. Without reference filters every spectrum counts as a reference and one average shift is applied to all.

5. Fit the region you care about

  1. Add the second + Peak Fitting for the analysis region, for example Region / band O1s (add an O 1s branch with its own Metadata Filter, Input = Initial), and pick a recipe.
  2. Background: a recipe with Replace includes an active Shirley background. Do not also add a static Shirley baseline step (the pipeline refuses to save). Use one or the other.
  3. Tune: set the Fit window to begin and end on baseline; adjust peak centres and bounds; add Links for doublets (FWHM equal, position offset).
  4. Check with View → After: fitting: look at the residual panel and at the RMSE/R²/BIC values for several spectra from different conditions.

6. Derive metrics

Add + Metric Calculation. Example: id ox_frac, formula {fit_O1s_p2_area}/({fit_O1s_p1_area}+{fit_O1s_p2_area}). Verify the names against the real exported columns later (see the caution on Features). Use your own peak names.

7. Save and run

  1. Name the pipeline (for example xps_O1s_v1), Save to library, Save pipeline.
  2. Analyze → dataset + pipeline → Run feature extraction (async) → wait for completed.
  3. Plots → Fit diagnostics: choose the fitting step and up to 10 spectra to verify the fits across conditions. Check there that no fit silently failed (a failed fit leaves empty columns and gof_success = 0).

8. Compare conditions and export

  1. Plots → Parameter vs parameter: X = meta_potential_V (or current density), Y = fit_O1s_p2_area or your metric, style Line + error bars if several spectra share a condition.
  2. Exports → Fitting curves → choose the fitting step and content data + fit + components + residuals → All PNG zip for figures; Observation wide CSV for the table.
XPS columns include the region name, such as fit_O1s_p1_pos. Give peaks meaningful names (for example lattice_O, OH) in the fitting editor: they end up in every column name.
