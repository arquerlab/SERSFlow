Analyze tab

The Analyze tab (“Features & statistics”) runs your saved pipeline on the entire dataset and then lets you explore the resulting feature table. The random subset used for previews in Prepare plays no role here.

Header controls

ControlWhat it does
DatasetChoose the dataset. Changing it clears the Pipeline and Run selections. Pipelines are filtered to the dataset's technique; a mismatch gives “technique_family mismatch”.
RunThe analysis run that drives Exports and the statistics. Entries show the run name and status.
PipelineShown only in Overview and Spectrum matrix & PCA. Pick a saved pipeline to run.
SectionOverview, Exports, Correlation / VIF, PCA / Cluster, Heatmaps, Plots, Spectrum matrix & PCA.

Your choices are remembered in the page address and in the browser, so a reload returns you to the same place. Computed results (PCA, k-means, correlation, VIF) are kept only in the open page and are lost on reload.

Overview: runs

  • Run feature extraction (async) starts a background job on every spectrum of the dataset (enabled once a dataset and pipeline are chosen). A line shows Job: … – status (done/total) and updates every second. The new run is selected automatically and is named “<dataset> <pipeline> NN”.
  • The Runs table lists Run, Status, Dataset, Pipeline and Created. Click a row to select it. Delete removes one run; Delete all runs removes all runs of the dataset, including running ones, with no undo. Saved exploration results and matrix jobs are kept.
  • Statuses: pending → running → completed or failed. Only one run executes at a time on the server; a second one waits as pending.
  • The server keeps at most 50 runs per dataset and automatically deletes the oldest.

What a run extracts

One feature table with a row per spectrum, built from the enabled Peak Identification, Peak Integration, Peak Fitting and Metric Calculation steps. QC steps (low-signal, outlier, metadata filter) remove spectra from the run. If the pipeline has no feature step, a default probe I_analysis_fallback (intensity at 1000 cm⁻¹) is added so the run is not empty. A spectrum whose extraction fails appears as an empty row.

The gate. Exports, Correlation/VIF, PCA/Cluster, Heatmaps and Plots show only a hint until the selected run is completed. If a run failed, the usual causes are: a crop that does not overlap the data, a fit window with no points left after cropping, or an unsaved pipeline. Fix it and start a new run.

Exports

Download buttons for the selected run. Details of every column are on Exports and column names.

  • Observation table (recommended): Observation wide CSV (labels + axes), Observation long CSV, Observation Parquet (wide) (needs the optional pyarrow package on the server).
  • Features only: Features wide CSV and Features long CSV (numbers only, ready for scikit-learn).
  • Manifest & bundle: Load manifest (JSON) shows provenance on screen; Bundle (ZIP, features only) contains the manifest plus the wide features CSV.
  • Fitting curves (on demand): only when the pipeline has fitting steps. Choose a Fitting step and a Content (“data + fit + residuals” or “data + fit + components + residuals”). Tick spectra and press Selected CSV zip / PNG zip / SVG zip (made in the browser), or use All CSV zip / PNG zip / SVG zip (a background job, up to 10 minutes of waiting). CSV columns: x, y, y_hat, residual and one comp_<id> per component.
  • Spectra with step outputs: tick pipeline steps and download one CSV per spectrum with the raw spectrum and the result of each chosen step. This re-runs the pipeline, so it can take a while.

Correlation / VIF

This is where you choose the feature columns for all statistics. The selection is shared by correlation, VIF, PCA and k-means; the PCA / Cluster section has no picker of its own.

  • Columns are grouped: Spectral features (with quick buttons for position, amplitude, area, FWHM, intensity families), Axes & grid and Experiment metadata (upload). Each group has Select all / Clear.
  • If your selection becomes empty (for example after switching run) it resets to all feature columns.
  • Run correlation draws a heatmap of the pairwise Pearson r. There is no method choice. Non-numeric metadata columns are dropped. More than 80 columns will be slow to draw.
  • Run VIF (needs at least two columns) draws the variance inflation factor per column. Rule of thumb: above 5 suggests collinearity, above 10 is strong. A perfectly redundant column gives an infinite value and its bar is blank.
  • Downloads: Correlation PNG/SVG and VIF PNG/SVG.
VIF, PCA and k-means use only the spectra that have a value in every selected column. If no spectrum qualifies, missing values are replaced by the column mean instead. The page does not tell you which happened. Mixing fit parameters with intensity features can therefore shrink the set of spectra used; check the observation table if numbers surprise you.

Buttons: Run PCA (or Run sparse PCA) and Run k-means.

Plot options

  • Plots to show: Scores scatter, PC vs metadata, Scores pairplot, Scree, Cumulative EVR, Loadings topN, Loadings heatmap, Cluster on scores, Cluster sizes.
  • PC axes default to PC2 vs PC3 (pairplot PCs 2–6; PC vs metadata PCs 2,3). Set “Scatter X PC”, “Scatter Y PC” and the PC lists to 1 if you want PC1.
  • Color by (metadata) colours scores by a numeric label. PC vs metadata plots a chosen PC against a metadata column (such as potential or time), one subplot per PC.
  • Loadings topN shows the N columns with the largest absolute loading per PC.
  • Each card has Download PNG / SVG / CSV; Export all PNG / SVG / CSV (zip) covers the plots currently shown.
  • After a PCA run: Download scores CSV, loadings CSV and variance CSV. The scores file also contains the file path, axes and all metadata, so it can be re-plotted elsewhere.
The server keeps one PCA result per analysis run. Running PCA again with other settings overwrites it, and downloading an older result gives you the newest one. Download what you need before changing settings.

The k-means table in the right panel shows only the first 80 labels. For all labels, tick “Cluster on scores” and download that plot's CSV (needs a PCA run).

Heatmaps

For maps (position on a surface) and time series. Needs spectra with map or time axes (see Tutorial 4).

  1. Choose a Feature (a run feature column).
  2. Files: All files, Single file or Multiple selected.
  3. Layout: Individual plots or Subplots.
  4. Press Plot heatmaps.

A map file gives a 2-D colour map; a time file gives a single-row map along time. Click a cell to overlay the processed spectrum from that position underneath (it re-runs the pipeline for that spectrum, so it may take a moment); Clear spectra empties the overlay. Each plot offers PNG and SVG.

Plots

Parameter vs parameter

Scatter any numeric column against another (features, metadata, axes). Per plot choose Style: Scatter, Line, Mean ± error bars, Line + error bars, Boxplot; then X, one or more Y (+ Y column), optional Color, optional X/Y error columns; press Plot. + Add plot adds another. Grouped styles group by identical X values; error bars are the sample standard deviation unless you supply an error column. Export as PNG, SVG or CSV.

Fit diagnostics

Pick a Fitting step and up to 10 spectra. SpecFlow re-fits them on demand and draws data, fit, individual peaks and residuals, with RMSE, R² and BIC for each. Use this to check that automatic fits across the dataset are sensible.

Spectrum matrix & PCA

Statistics on whole spectra rather than on extracted peaks. Not gated by a completed run.

  1. Select the pipeline and, optionally, up_to_step: Final (all steps), Raw spectra or a numbered step.
  2. Press Start matrix job (async). This builds a table with one row per spectrum and one column per wavenumber for the full dataset.
  3. Select the finished job in the table (Use). Download it with Download matrix CSV, or load one back with Import matrix CSV.
  4. Run Run discrete PCA, k-means (PC embedding) or the functional FDA FPCA.
  • All spectra must share the same x grid. Otherwise the job fails with “inconsistent Raman shift grid”. Add an Alignment & Resampling step after cropping and set up_to_step to that step or later.
  • If a Run is selected, the job uses that run's stored pipeline, not the Pipeline dropdown.
  • FDA FPCA needs the optional scikit-fda package on the server (pip install -e ".[explore-fda]").
  • Discrete method: PCA on Y or Sparse PCA on Y, with the same Scaling choices. Unit-variance scaling can amplify noisy regions; use it deliberately. Loadings are spectra: the plot shows each PC's loading against wavenumber, which you read like a difference spectrum.
  • Spectrum k-means: k, seed and n_pc_embedding (how many PCs feed the clustering).
  • Downloads: scores, loadings, variance and mean-spectrum CSVs for discrete and FDA results.
