Features: integration, peaks, metrics

Feature steps do not change the spectrum. They add columns to the table that Analyze produces. Together with Peak Fitting they define what you can correlate and plot.

Peak Identification

Reads an intensity (and optionally a peak position) at places you define. Press + Add probe for each.

SettingMeaning
idName used in the column (p1, p2… if empty).
sourcesignal (processed spectrum) or baseline (with “baseline step”: samples the estimated baseline curve).
targetPosition to read (default 1000; eV for XPS).
acquisitionfixed (interpolate at target) or nearest_peak (with an optional window around the target).
methodlinear_interp or nearest.
extrapolationnan (outside range) or clip.
no_peak_fallbacknone or fixed_nearest (use the intensity at the target if no peak is found).

Columns: I_<id>, and for nearest_peak also peak_pos_cm1_<id>.

nearest_peak counts every local maximum as a peak (no height or prominence limit). On noisy spectra it can lock onto a noise bump. Always set a window and smooth first.

Peak Integration

Integrates the spectrum over x windows (+ Add window).

  • id (band1, band2…), min and max (defaults 1900 and 2150; enter eV for XPS), mode: signed, positive only (negatives clipped to 0) or absolute.
  • Column area_<id>. Trapezoid rule with interpolated edges. A window that only partly overlaps the spectrum integrates just the overlap; no overlap gives an empty value.
  • No baseline is removed automatically: place it after Baseline Correction.
  • This step integrates windows only. Areas of fitted peaks come from Peak Fitting (fit_…_area).

Metric Calculation

Computes new columns from columns produced by earlier feature steps, for example ratios.

  • + Add operation: id (the column becomes op_<id>) and a formula.
  • Write columns in braces: {fit_p1_area}/{fit_p2_area}, log10({area_band1}/{area_band2}). Allowed: + - * / ** % ( ), numeric constants and the functions abs sqrt log log10 exp min max.
  • Insert variable or the list of available variables inserts a name for you.
  • Evaluated per spectrum. A missing input, a division by zero or a math error gives an empty cell, not an error.
The variable list shows fit names without the XPS region and without the s<N>_ prefix used when a pipeline has several fitting steps. If a metric comes out empty, compare your formula with the real column names in the exported table (Exports and column names) and edit the formula to match.

Where do the columns end up?

When you press Run feature extraction (async) in Analyze, all enabled feature steps contribute columns, in step order. If the pipeline has none, a default probe is added so the run is not empty.

Plan your questions before building the pipeline: “How does the CO band area change with potential?” needs an integration or fit of that band plus a potential label.
